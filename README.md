# BlinkIT-Sales-Analytics-Dashboard
Blinkit Sales Analytics Dashboard built in Power BI to analyze outlet performance, sales trends, item distribution, customer ratings, and outlet characteristics. The dashboard provides interactive insights into total sales, average sales, item categories, outlet size, location, and establishment trends, enabling data-driven business decisions. 📊🚀
